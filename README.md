# 🎮 Number Guessing Game Using Python

## Project Overview
The Number Guessing Game is a simple, interactive, and beginner-friendly Python project designed to provide an enjoyable gaming experience while demonstrating fundamental Python programming concepts. In this game, the computer randomly generates a secret number between 1 and 100, and the player must guess the correct number.

The game guides the player by providing helpful hints after every attempt. If the entered number is smaller than the secret number, the program displays "Too Low! Try Again." If the entered number is greater, it displays "Too High! Try Again." Once the player guesses the correct number, the program displays a congratulatory message along with the total number of attempts taken.

## 🚀 Features
- **Random Number Generation:** Generates a random number between 1 and 100 using Python's random module.
- **Interactive Gameplay:** Allows users to enter guesses through the console.
- **Smart Hints:** Provides "Too High" and "Too Low" messages to guide the player.
- **Attempt Counter:** Tracks the total number of valid guesses.
- **Error Handling:** Uses try-except exception handling to prevent invalid inputs from interrupting the game.
- **Simple Interface:** Easy-to-understand console-based gameplay.

## 🛠️ Technologies Used
- Python
- Random Module
- While Loop
- Conditional Statements (if-elif-else)
- Exception Handling (try-except)
- User Input and Output Functions

## ⚙️ How to Run the Project

1. Install Python on your computer.
2. Clone or download this repository.
3. Open the project folder in VS Code or any Python IDE.
4. Open the terminal.
5. Execute the following command:

`python number_guessing_game.py`

6. Start guessing the randomly generated number!
